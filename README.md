# Molecular Computing Experiments

Exploration of computational methods for DNA strand substitution, starting from abstract chemical reaction networks and gradually progressing to ultimately realize molecular neural networks.

## Current progress

- [x] Abstract CRN simulation with ODEs
- [x] Molecular AND-like reaction
- [x] Chemical threshold / ReLU-like behavior
- [x] Domain-level DNA binding with Peppercorn
- [x] Toehold-mediated strand displacement
- [x] Kinetic simulation with Pilsimulator
- [ ] Toehold engineering
- [ ] Molecular perceptron
- [ ] Small molecular neural network
- [ ] Neural-network-to-DSD compilation
